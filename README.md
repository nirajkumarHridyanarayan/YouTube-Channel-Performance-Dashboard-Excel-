📌 Project Overview

This project presents an interactive YouTube Channel Performance Dashboard built using Microsoft Excel.
The dashboard provides a comprehensive analysis of YouTube channels and videos, focusing on views, likes, comments, video types, categories, engagement, and publishing trends.

The goal of this project is to analyze content performance, identify viewer engagement patterns, and compare Long vs Short video formats using data visualization and Excel analytics.

📊 Dashboard Features & Insights
🔹 Video Distribution by Category

Shows how videos are spread across categories such as:

Entertainment

Education

Music

Gaming

Film & Animation

Comedy

Autos & Vehicles, etc.

🔹 Total Views by Video Type

Compares Long-form vs Short-form videos

Shorts generate significantly higher total views compared to Long videos.

🔹 Likes vs Comments per Video

Visual comparison of user engagement on top-performing videos.

Highlights interaction differences between likes and comments.

🔹 Top 5 Most Viewed Videos

Displays the most popular videos based on total views.

Helps identify content themes with maximum reach.

🔹 Monthly Trend of Videos Published

Shows publishing activity trends over time.

Useful for identifying growth patterns and content consistency.

🔹 Channel Engagement vs Total Views

Compares engagement rate with total views for selected channels.

Helps analyze audience quality vs quantity.

🔹 Average Video Duration by Type

Comparison of average duration for:

Short Videos

Long Videos

🎛️ Interactive Filters (Slicers)

The dashboard includes slicers for:

Video Type (Long / Short)

Category Name

Year-Month (Time Period)

These filters allow users to dynamically explore the data and gain deeper insights.
